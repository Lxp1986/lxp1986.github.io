FreeCAD 导 DXF 丢文字标注，换旧版导出器就好了

发表于2026-08-25|更新于2026-09-15|工程软件
|浏览量:

画施工图这行，FreeCAD 出图之后绕不开一步：导 DXF。我的流程是 FreeCAD 里画好，导 DXF 给做预算的或者施工队，对方用 LibreCAD 或者 CAD 打开接着干活。

上个月给一个村道项目的排水断面图收尾，画完导 DXF 发出去，隔天对方回一句：标注呢？我打开文件一看，线都在，尺寸标注全没了，图上的文字说明也一个不剩。图能看，但没尺寸没标注，等于白画。

查了半天，问题出在 FreeCAD 的默认导出器上。

两个导出器，差在哪

FreeCAD 里有两套 DXF 导出器：

  • C++ 导出器：默认用的这个，速度快，但导出的东西少
  • 旧版 Python 导出器：慢，但功能全

官方文档里的对比表列得很清楚：文字和标注、颜色、组和块，默认的 C++ 导出器一概不导出。也就是说你在 Draft 工作台里标了一堆尺寸、写了几行说明，导出来只剩几何线。速度快是快，该丢的一样没少丢。

第一步：换旧版导出器

解决就一步：

  1. 打开 FreeCAD，菜单：编辑 → 偏好设置 → 导入/导出 → DXF
  2. 勾选「使用旧版 Python 导出器」（Use legacy python exporter）
  3. 如果提示需要下载 DXF 转换库，把「允许自动下载并更新 DXF 库」也勾上——这个库因为许可证原因不能打包进 FreeCAD，第一次会自动下载，之后就没事了
  4. 重新导出，文字标注就回来了

中文变方块，是字体的事

换旧版导出器之后，文字是有了，但 LibreCAD 里打开全是方块。一开始以为导出坏了，后来才搞明白：DXF 里的文字内容是 Unicode，没坏，坏的是打开端的字体映射。TEXT 实体里带一个字体名，LibreCAD 找不到对应字体，就画方块。

处理办法：LibreCAD 里选中文字，属性编辑器里把字体换成系统里带的中文字体，方块立刻变回字。更省事的做法是导出前在 FreeCAD 里把 Draft 文字对象的字体属性设成系统里真实存在的中文字体，一劳永逸。

曲线和图层，两个边角料

旧版导出器对椭圆支持不好，官方论坛都承认这事。河道断面、边坡这种带曲线的图，用旧版导出器，椭圆容易出问题。我的做法是看情况：曲线多就先用默认导出器把几何出干净，标注到 LibreCAD 里补；曲线少就直接旧版一把梭。要是用脚本导出，importDXF.export() 里有个 nospline 参数，默认 False 按样条导，设 True 就把样条离散成多段线，跟下游软件不兼容时可以试这个。

图层也顺带说一句。默认导出器按对象名映射图层，旧版按 Draft 工作台的图层（Layer）映射。想让 DXF 里图层名可控、分得清，画的时候就把线分门别类放进 Draft 图层里，导出后在 LibreCAD 里才好开关图层。工程图不分层，后面改图能改到哭。

现在的流程固定下来了：Draft 工作台里把几何和标注都画好，图层分好，旧版导出器导出，LibreCAD 打开核对一遍字体，再发出去。没再出过丢标注的事。官方文档在 wiki.freecad.org/Draft_DXF，对比表值得存个书签。
